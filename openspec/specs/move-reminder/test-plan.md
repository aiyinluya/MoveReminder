# 手工测试计划 — 动动提醒

环境：Windows 10/11，x64，已安装 .NET 8 桌面运行时（若使用 framework-dependent 发布）。

## 冒烟（每次构建）

1. `dotnet build -c Release` 无错误。
2. 运行 exe：托盘为**自定义图标**（非默认「应用程序」系统图标）；打开设置点击「保存」后，确认 `%LocalAppData%\MoveReminder\settings.json` 已生成/已更新（可用记事本打开核对字段）。
3. 退出程序再启动：上次修改的间隔/文案/模式应保持（持久化回归）。
4. 托盘菜单：点「推迟 10 分钟」后，托盘提示「下次约」时间应顺延约 10 分钟；「跳过下一次」应重排为从当前起一整间隔。
5. 「关于」对话框能显示版本号且可正常关闭。
6. 打开「设置」：**常规**卡片 + **「提醒内容」**卡片（文字/图片/创意单选）；设置页**无**「保存后生效」类提示；全屏时底部有**倒计时**（与设置中「自动关闭」秒数一致）。

## 功能

| 步骤 | 期望 |
|------|------|
| 设置间隔为 1 分钟，保存 | 约 1 分钟后弹出全屏（未锁屏） |
| 弹出后按 Esc 或等到自动关闭 | 全屏层关闭 |
| 托盘「立即提醒」 | 立刻弹出（未锁屏） |
| 切换为图片模式，选有效 png | 弹窗显示图片 |
| 文字模式下选推荐色或「其他颜色」保存 | 全屏主文案使用该颜色；`settings.json` 含 `reminderTextColorHex` 或与默认同色时为空 |
| 选中「图片提醒」并保存 | `ReminderMode` 为图片；仍为「文字提醒」时保存则仍为文字 |
| 先选「图片提醒」再浏览选图并保存 | 路径写入缓存目录引用；主预览与右侧「最近使用」均更新 |
| 先选「创意提醒」再浏览选择 GIF，选择「全屏自适应」后保存 | 路径写入 `creative/cache/`；触发提醒时 GIF 铺满屏幕播放 |
| 创意模式下导入多个 GIF 后点击「最近使用」缩略图 | 路径切换到所点 GIF，预览刷新且缩略图高亮同步 |
| 先选「创意提醒」并选择「自定义尺寸」，设置显示大小后保存 | 触发提醒时 GIF 按设置尺寸居中播放，倒计时透明悬浮且不占用内容高度 |
| GIF 创意提醒等待自动关闭时间 | 即使 GIF 持续播放，倒计时也应按真实剩余时间刷新，到时自动关闭 |
| 文字颜色区 | 预览块与 HEX 随选择变化；悬停推荐色有 ToolTip |
| 图片路径故意填错 | 回退文本或友好提示，不崩溃 |
| 勾选「保存后立即展示」并点击保存 | 设置窗口关闭后立即弹出一次提醒；关闭后按提醒间隔进入下一轮 |
| Win+L 锁屏，等待超过间隔 | 锁屏期间不弹；解锁后等待一个完整间隔再弹 |
| 合盖或睡眠（若设备支持） | 睡眠中不弹；唤醒后行为正常 |
| 勾选开机自启动，保存 | `HKCU\...\Run\MoveReminder` 存在且指向当前 exe |
| 取消勾选 | 注册表项删除 |
| 再次双击启动第二个实例 | 提示已运行，进程不重复 |
| 修改任意设置后点「保存」 | 无报错；`settings.json` 时间戳更新；托盘「下次约」时间随间隔变化 |
| 点「取消」或关闭窗口 | 不覆盖 `settings.json`（与打开前一致） |

## 按角色的关注点（团队视角）

| 角色 | 测什么 |
|------|--------|
| 产品/设计 | 默认文案、间隔范围、图片失败回退、锁屏不打扰是否符合预期文案与流程 |
| 开发 | 保存路径、JSON 字段、注册表自启与 exe 路径、单实例、线程封送无异常 |
| 测试 | 上表功能矩阵 + 边界（间隔最小/最大、空文字、空图片路径、无效图片） |
| 技术支持/用户 | 配置位置 `%LocalAppData%\MoveReminder\`、需安装 .NET 8 桌面运行时（非自包含发布时）、杀毒/权限导致保存失败时是否有明确错误提示 |

## 回归关注点

- **多显示器**：应出现与屏幕数量相同的全屏层，每屏内容居中；每屏底部有**倒计时**；任一处按 **Esc** 或倒计时到 0 后全部消失；无按钮。
- **单显示器**：仅一扇全屏；底部有倒计时一行。
- 长时间运行：内存是否稳定（任务管理器粗看）。
