# 能力规格：动动提醒（Move Reminder）

## 目的

帮助久坐用户按固定间隔收到**全屏**提醒，促使其起身活动；在不可用场景（锁屏、休眠）下静默，避免无效打断与误触。

## 用户场景

1. 用户双击 `MoveReminder.exe` 启动；程序无主窗口，仅在任务栏通知区域（托盘）显示图标。
2. 用户通过托盘菜单打开「设置」，配置间隔、提醒内容、是否开机启动等。
3. 到达间隔时间且系统处于**已解锁且未休眠**状态时，弹出置顶全屏提醒层；用户按 **Esc** 或到达自动关闭时间后结束，进入下一轮间隔计时。
4. 用户从托盘退出后进程结束；若开启开机自启动，下次登录后自动运行。

## 功能需求

### FR-1 托盘常驻

- 程序启动后在托盘显示**品牌化图标**（与 exe `ApplicationIcon` 一致，高 DPI 下使用系统小图标尺寸缩放显示）。
- 托盘菜单（参考 Stretchly / WorkRave 等休息类软件）至少包含：**立即提醒**、**推迟 10 分钟**、**推迟 30 分钟**、**跳过下一次**（从当前时刻起按设定间隔重新排程）、**设置**、**关于**、**退出**；菜单使用浅色悬停高亮，避免纯系统默认灰块。
- 关闭/最小化行为：无独立主窗口时，仅以托盘存在；退出仅通过菜单「退出」。

### FR-8 界面与品牌化（设置 / 关于）

- **设置**：顶栏品牌色 + 标题/副标题；主体浅灰背景；**常规**为一块白底卡片（细描边）：提醒间隔、自动关闭秒数、保存后立即展示、开机自启动；**勿**在设置页堆砌全屏操作说明或「保存后生效」类延迟提示文案。
- **提醒内容卡片**：标题为「提醒内容」；卡片内顶部为**同一组单选**：「文字提醒」「图片提醒」「创意提醒」，与 **`ReminderMode`** 一致；下方区域随单选切换展示文字配置、图片配置或创意配置（非 Tab）。
- **文字模式**：多行「提醒文字」输入首屏可见（首行固定合理高度，避免被父布局压成 0）；**文字颜色**含圆角预览块、**#RRGGBB** 粗体、「其他颜色…」（系统 `ColorDialog`）、**推荐色**标题与**圆形色点**；推荐色区域须具备**稳定可见高度**（固定行高或等效），不得因父级 `Percent` 行高为 0 而消失；推荐色悬停 **ToolTip** 为简短预设名；选中时品牌色外环。
- **图片模式**：图片路径与「浏览…」**同一行**（路径可伸缩、按钮固定宽）；其下为**左右分栏**（约 62% / 38%）：左侧为主预览（`Zoom`、等比缩略），右侧为「最近使用」标题 + 缓存目录内最近文件的**缩略图网格**（可滚动），与主预览**同屏并列**；点击缩略图即将路径写入当前选用并刷新预览与高亮。
- **创意模式**：首版支持导入本地 GIF；路径与「浏览…」同一行，选择后复制到与配置同根的 `creative/cache/`；设置页展示静态预览、缓存目录内最近 GIF 的缩略图、显示方式（全屏自适应 / 自定义尺寸）和单一显示大小百分比；点击最近使用缩略图即将路径写入当前选用并刷新预览与高亮；全屏提醒按设置方式播放 GIF 动画，加载失败时回退文字提醒。
- **关于**：独立对话框展示程序集版本号与简要说明、配置目录提示；风格与设置一致。
- **全屏提醒**：不展示操作按钮与冗长说明条；**底部居中悬浮展示自动关闭剩余秒数**（如「42 秒后关闭」），使用透明背景文字与阴影，每秒刷新，不占用提醒内容布局高度。

### FR-2 间隔提醒

- 默认间隔：45 分钟；可在设置中修改（范围建议 5–480 分钟）。
- 使用单一计时器：上次提醒结束（或应用启动）后重新开始倒计时。
- **锁屏期间**：不弹出提醒；锁屏计时逻辑见「会话与电源」。
- **休眠/睡眠期间**：不弹出提醒；唤醒后按规格恢复计时。

### FR-3 全屏提醒呈现

- **单显示器**：一扇无边框置顶窗体，边界与该屏 `Screen.Bounds` 一致，内容在该窗体客户区内居中。
- **多显示器**：为 `Screen.AllScreens` 中每一扇物理屏各创建一扇全屏窗体（`Bounds` 等于该屏 `Screen.Bounds`），内容**分别在各屏内居中**，避免「单窗体横跨虚拟桌面、内容落在两屏接缝」；任一屏上 **Esc** 或倒计时结束，**整组窗体同时关闭**。图片提醒时共享一份解码后的位图，避免多屏重复占用内存。
- 置顶，无边框。
- **文本模式**：显示可配置主文案（默认：「该起来活动一下了」）；**文字颜色**在设置「提醒内容」卡片内选中「文字提醒」时配置（见 **FR-8**），持久化为 `#RRGGBB`；非法或缺失时回退为默认柔白；底部仅保留悬浮自动关闭倒计时，无按钮。
- **图片模式**：显示用户选择的本地图片（支持常见位图格式）；**等比放大直至铺满当前屏可视区域，超出部分裁切**（类似 `object-fit: cover`），不拉伸变形；图片路径无效时回退为文本模式，可在提醒区保留一行简短说明。设置中通过「浏览」选图时，程序将文件**复制**到与配置同根目录下的 `images/cache/` 并引用该路径；设置页展示**预览**与**缓存目录内最近选用**缩略图以便再次选择。
- **创意模式**：显示用户选择的本地 GIF 动画；全屏自适应时按 cover 规则铺满当前屏，自定义尺寸时按显示大小百分比在当前屏内居中等比播放，均不拉伸变形；GIF 路径无效或加载失败时回退为文本模式，可在提醒区保留一行简短说明。
- **自动关闭**：到达配置的秒数后自动结束全屏提醒（默认 60 秒，可配置），防止无人值守时长期遮挡；GIF 动画播放不得导致自动关闭失效，倒计时应按真实截止时间刷新。
- 快捷键：**Esc** 关闭整组全屏提醒。

### FR-4 会话与电源（不打扰）

- **锁屏**：通过 `Microsoft.Win32.SystemEvents.SessionSwitch` 检测 `SessionLock` / `SessionUnlock`。锁屏期间禁止弹出；解锁后不补发「错过的」提醒，从解锁时刻起重新计时间隔（与实现一致即可，需在用户文档中说明）。
- **休眠/睡眠**：订阅 `Microsoft.Win32.SystemEvents.PowerModeChanged`，在 `Suspend` 进入静默；`Resume` 后恢复计时。挂起期间不得弹出。

### FR-5 设置持久化

- 用户点击设置窗口的「保存」且校验通过时，必须写入 `settings.json`；**不得**因 `FormClosing` 的 `CloseReason` 误判而跳过保存（实现上：以 `DialogResult == OK` 为准，勿错误限定为 `UserClosing`）。
- 配置文件默认路径：`%LocalAppData%\MoveReminder\settings.json`（若目录不存在则创建）。**便携**：若 exe 同目录存在空文件 `MoveReminder.portable` 或已存在 `settings.json`，则读写**与 exe 同目录**的 `settings.json`（路径按 `Environment.ProcessPath` 解析，与单文件解压目录无关）。
- 字段至少包含：`IntervalMinutes`、`ReminderMode`（`Text` | `Image` | `Creative`）、`ReminderText`、`ReminderTextColorHex`（可选，空表示默认文字色）、`ImagePath`、`CreativeGifPath`、`CreativeGifLayoutMode`、`CreativeGifSizePercent`、自动关闭秒数、`ShowImmediatelyAfterSave`、`StartWithWindows`、`LastSavedUtc`（可选）。
- 保存后立即应用：间隔、模式、文案/图片、自动关闭秒数、开机启动项。

### FR-6 开机自启动

- 开启：在 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入项 `MoveReminder`，值为当前 exe 的完整路径（带引号以兼容空格路径）。
- 关闭：删除该注册表项。
- 若用户移动 exe 位置，需重新保存设置或重新勾选以更新注册表路径。

### FR-7 单实例

- 同一用户会话仅允许一个实例；第二个启动时给予提示并退出。

## 非功能需求

- **NFR-1 资源**：空闲时 CPU/内存占用应极低（托盘计时器 + 少量事件订阅）。
- **NFR-2 隐私**：除本地设置与注册表自启动项外，不上传数据、不访问网络（本实现不包含任何 HTTP 客户端）。
- **NFR-3 可维护性**：设置模型与 UI 分离，便于后续单元测试扩展。
- **NFR-4 高 DPI**：在 `PerMonitorV2` 策略下，设置与关于窗体布局清晰；不在 `app.manifest` 与项目属性中重复声明冲突的 DPI 元数据（避免 WFAC010 类警告）。

## 验收标准（测试映射）

| ID | 场景 | 期望 |
|----|------|------|
| AC-1 | 启动应用 | 托盘出现图标，无错误对话框 |
| AC-2 | 间隔到达且未锁屏 | 全屏提醒出现，置顶 |
| AC-3 | 锁屏状态下间隔到达 | 不出现提醒；解锁后按策略重新计时 |
| AC-4 | 休眠唤醒后 | 不出现休眠期间的积压弹窗；恢复后行为正常 |
| AC-5 | 修改间隔并保存 | 下一轮按新间隔执行 |
| AC-6 | 切换文本/图片/创意 | 弹窗内容符合设置 |
| AC-10 | 设置文字颜色并保存 | 全屏主文案使用该颜色；配置可持久化 |
| AC-11 | 打开设置 | 可见「常规」卡片 + **「提醒内容」卡片**（文字/图片/创意**单选**）；图片模式下路径与「浏览」同行，**主预览与「最近使用」缩略图同屏并列**；创意模式下可导入 GIF、预览、从最近使用缩略图中选用，并设置全屏自适应或自定义显示大小百分比；文字模式下含颜色预览、HEX、其他颜色与**稳定可见的圆形推荐色** |
| AC-7 | 开机自启动开关 | 注册表项存在/删除与 UI 一致 |
| AC-8 | 二次启动 | 提示已运行并退出 |
| AC-9 | Esc 或自动关闭时间到 | 整组提醒关闭 |
