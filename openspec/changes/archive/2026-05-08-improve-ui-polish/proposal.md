# 变更提案：界面品牌化与体验优化

## 背景

首版功能完整但视觉偏「默认 WinForms」；托盘图标为系统占位符，与同类成熟产品（Stretchly、WorkRave、Time Out 等）相比缺少品牌化与快捷操作。

## 目标

- 自定义应用/托盘图标（与 exe 资源一致），高 DPI 下清晰。
- 设置窗体：分区布局、浅色卡片、主色按钮，符合主流桌面应用观感。
- 全屏提醒：主按钮与底色更克制、易读。
- 托盘菜单：推迟提醒、跳过下一次、分组与易读标签；可选浅色/系统菜单渲染。
- 关于：展示程序集版本与配置路径。

## 范围

- 包含：图标资源、`UiTheme`、`AboutForm`、托盘与设置 UI、DPI 配置、规格与测试计划增量。
- 不包含：主题切换引擎、云同步、统计报表。

## 状态

已实现并合并进 `openspec/specs/move-reminder/spec.md` 对应段落。
