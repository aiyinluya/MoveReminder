# 变更提案：Windows 动动提醒桌面助手

## 背景

久坐健康风险高，需要轻量、本地、可配置的定时全屏提醒；且在工作场景锁屏/休眠时不应打断或误触。

## 目标

交付可双击运行的 Windows 桌面程序：托盘常驻、可配置间隔与提醒样式（文本或图片）、锁屏/休眠静默、可选开机自启动。

## 范围

- 包含：托盘、设置窗体、全屏提醒窗体、JSON 配置、注册表自启动、单实例、会话与电源事件。
- 不包含：自动更新、云同步、移动端。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 多显示器坐标差异 | 使用虚拟屏幕边界 `SystemInformation.VirtualScreen` |
| 图片路径失效 | 回退文本模式并提示 |
| 注册表权限 | 仅 HKCU，一般用户可写 |

## 状态

已实现；规格已写入 `openspec/specs/move-reminder/spec.md`。
