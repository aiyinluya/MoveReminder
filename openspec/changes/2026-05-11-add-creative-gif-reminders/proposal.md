# 变更提案：创意 GIF 提醒

## 背景

现有提醒内容仅支持文字与静态图片。用户希望在不准备复杂素材包、不引入云端依赖的前提下，使用外部 AI 生成的短动画素材，让全屏提醒更有吸引力。

## 范围

- 新增独立的 **创意提醒** 模式，与文字提醒、图片提醒并列。
- 首版仅支持导入本地 **GIF** 文件，程序复制到配置同根目录下的创意素材缓存目录。
- 设置页提供 GIF 路径、浏览导入、预览、显示方式（全屏自适应 / 自定义尺寸）和单一显示大小百分比。
- 全屏提醒按选择的显示方式播放创意 GIF，并继续保留现有倒计时、Esc 关闭、多显示器与自动关闭行为。
- 倒计时改为悬浮显示，不再占用提醒内容区域。
- 创意 GIF 无法加载时回退为文字提醒，并给出简短说明。

## 非目标

- 不在首版内置在线素材库或联网下载。
- 不接入外部 AI API。
- 不支持 MP4/WebM 播放；视频播放依赖与发布体积另行评估。
- 不要求用户手动维护 manifest、封面、分层素材或素材包目录结构。

## 验收

- 设置页「提醒内容」卡片中可选择「创意提醒」。
- 选择 GIF 后会复制到本地缓存，并可在设置页预览。
- 保存后触发全屏提醒时，GIF 能全屏自适应播放，或按设置的显示大小百分比居中等比播放。
- 文字提醒与图片提醒原有行为不回退。
- `dotnet build .\MoveReminder.sln -c Release` 通过。
