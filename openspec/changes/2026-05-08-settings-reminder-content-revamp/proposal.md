# 变更提案：提醒内容区（文字推荐色 + 图片历史并列）

## 背景

设置页需同时满足：

1. **文字模式**：推荐色以圆形色点形式**稳定可见**，不得因 Tab/表格行高为 Percent 而被压成 0 高度。
2. **图片模式**：主预览与**缓存历史缩略图在同一屏内并列展示**，避免「先看大图、再滚下去找历史」的割裂感。
3. **文案**：去掉「保存后生效」等口语化延迟说明；全屏 Esc 等说明不再在设置页堆砌（与既有精简方向一致）。

## 范围

- `SettingsForm`：提醒方式由 **Tab** 改为同卡片内 **单选（文字提醒 / 图片提醒）**；图片区路径与「浏览」同一行；主预览与「最近使用」左右分栏。
- `TextColorPickerSection`：推荐色区域使用**固定行高**（或等效布局），保证色点始终占位。
- `openspec/specs/move-reminder/spec.md` 与测试计划中对 FR-8 / AC-11 的表述同步更新。

## 非目标

- 不改变 `settings.json` 字段语义与保存逻辑。
- 不新增网络或云同步。

## 验收

- 打开设置：在「提醒内容」卡片内可见单选；文字模式下可见「推荐色」及全部预设圆点；图片模式下可见大图预览与右侧（或并列区域）历史缩略图，且可点击选用。
- 界面文案不出现「保存后生效」。
- `dotnet build -c Release` 通过。
